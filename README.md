# AI-Powered E-Commerce Business Analytics & GenAI Insight System

## 📊 Project Overview

An end-to-end e-commerce analytics and GenAI project built using Python, Pandas, Power BI, and a local Large Language Model (LLM).

The project analyzes 30,000 e-commerce records to understand sales performance, product trends, customer behavior, discounts, returns, refunds, and profitability. It also provides a GenAI-powered business Q&A system that converts analytical results into natural-language business insights.

## 🚀 Key Features

- Sales and profit analysis
- Product and category performance analysis
- Customer behavior analysis
- Discount and return analysis
- Interactive Power BI dashboard
- KPI and business performance reporting
- GenAI-powered business Q&A
- Ground-truth validation for analytical answers
- Hallucination protection for AI-generated insights

- Order Status
- Discounts
- Returns and Refunds
- Monthly Sales Trends

## 🤖 GenAI Business Q&A

A local LLM-based question-answering system was developed to allow users to ask business questions in natural language.

Example questions:

- Which category generated the highest sales?
- What is the total profit?
- Which products performed best?
- What is the return rate?
- How did discounts affect sales?

The system validates important analytical results against ground-truth business metrics to reduce hallucinated answers.
