# Power BI Sales Performance & Customer Analytics Dashboard

## 📊 Project Overview

This project is an interactive Power BI dashboard designed to analyze sales performance, customer behavior, product performance, and order trends.

## 📁 Dashboard Pages

### 1. Sales Performance & Customer Analytics
- Overall Sales Performance
- Monthly Sales Trend
- Sales by Category
- Sales by City
- Customer Analysis

### 2. Product & Sales Deep Dive
- Product & Category Sales Analysis
- Sales vs Discount Analysis
- Category Slicer

### 3. Customer Analysis
- Top 10 Customers by Sales
- Sales by Customer Gender
- Sales by Customer Age
- Sales by Customer Type
- Sales by Customer Rating

### 4. Order & Delivery Analysis
- Order Status Distribution
- Payment Method Distribution
- Monthly Order Trend
- Order Status by Payment Method

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## 🎯 Project Objectives

- Analyze sales performance
- Identify top-performing products and categories
- Understand customer behavior
- Analyze order and payment patterns
- Track monthly sales trends
- Compare sales and discounts
